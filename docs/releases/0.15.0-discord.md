# Jellystack v0.15.0 - Watch together and take control

Jellystack 0.15.0 adds some of the most requested server and playback features yet:

- Server-configured Home Sections support
- Jellyfin SyncPlay groups for watching together
- Per-session playback speed and live Stats for Nerds
- A new Admin tab for Jellyfin administration and pending Seerr requests

Home Sections can be disabled under Appearance if you prefer Jellystack's original Home layout. The Admin tab only appears for Jellyfin administrators, and Seerr actions follow the connected account's permissions.

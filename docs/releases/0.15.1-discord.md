# Jellystack 0.15.1 — server-powered playback segments

Jellystack 0.15.1 makes Jellyfin's server-provided playback markers useful on every supported Android phone and tablet:

- Skip intros, recaps, previews, commercials, and credits with clear in-player actions
- Choose Off, Button, or Auto independently for each segment type in Settings
- Play the next episode while credits are on screen

Segment availability and timing come from your Jellyfin server. Thanks for testing, and please report the server version and playback steps when a marker is missing or misplaced.

Download: https://github.com/Darkatek7/jellystack/releases/tag/v0.15.1

# Jellystack v0.14.1 — Quick Connect

@everyone

Jellystack v0.14.1 makes connecting your Jellyfin server faster and safer:

- Connect Jellyfin with a secure six-digit Quick Connect code
- Link Seerr automatically after Jellyfin Quick Connect when supported
- Approve the device through Jellyfin under **Profile → Quick Connect**
- Switch to username and password whenever Quick Connect is unavailable
- Use the same streamlined flow during onboarding and under **Settings → Connections**
- Store the authorized token and device identity securely without retaining a Jellyfin password

Quick Connect is now the default for new Jellyfin connections, while the full password login remains one tap away.

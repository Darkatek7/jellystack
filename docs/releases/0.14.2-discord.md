# Jellystack v0.14.2 — Trust & Open Source

Jellystack 0.14.2 is focused on transparency and trust:

- 🔒 Significantly reduced Android permissions
- 🧭 Clear permission and privacy explanations in Settings
- 📡 Cast permissions are requested only when the feature needs them
- 🛡️ Stronger credential, logging, and HTTP connection safeguards
- 💜 Jellystack is now fully open source under AGPL-3.0

Source: <https://github.com/Darkatek7/jellystack>

Jellystack remains independent and is not affiliated with or endorsed by Jellyfin or Seerr.

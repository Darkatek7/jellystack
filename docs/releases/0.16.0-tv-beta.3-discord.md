# Jellystack 0.16.0 TV Beta 3 — a more cinematic Home

TV Beta 3 gives Jellystack a more immersive, remote-first look and feel on Android TV, Google TV, and Fire TV.

- A larger Home hero carousel featuring recently added Jellyfin media
- Direct left/right carousel navigation with stable D-pad focus
- Local Jellyfin trailer previews on Home cards after a short pause
- Separate settings for trailer previews and preview sound
- More predictable vertical navigation across Home rows and the navigation rail
- Redesigned full-bleed detail pages with clearer actions
- A fix for details opening partially scrolled, so the complete artwork remains visible and Up returns to the hero

This is a beta release. Please share your TV or Fire TV model, OS version, and the navigation or playback steps if you run into an issue.

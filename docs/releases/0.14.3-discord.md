# Jellystack v0.14.3 - Stability update

Jellystack 0.14.3 is focused on the issues reported since the open-source release:

- Seerr requests now respect your server permissions.
- IP addresses, custom ports, IPv6, and reverse-proxy paths work reliably.
- Audio compatibility and actual language-track selection are improved.
- Discover search stays open while you type.

Thanks to everyone who tested the production release and reported these problems. Your feedback directly shaped this update.

# Jellystack 0.16.0 TV Beta 6 — profiles and cinematic browsing

TV Beta 6 is the largest Jellystack TV update so far. It adds household profiles, a Netflix-style preview stage, faster library discovery, and a broad focus/navigation reliability pass for Android TV, Google TV, and Fire TV.

- Browse Home, Library, Search, and Discover with a large backdrop and trailer stage above static media cards
- Use separate Jellyfin household profiles with real usernames and avatars, optional PIN protection, isolated preferences, and safe atomic switching
- Keep each profile’s Jellyfin favorites and locally saved Seerr titles together in My List
- Switch Library between cinematic Browse rows and a clean, paged All Titles grid with sorting and filters
- Search Jellyfin and Seerr together, merge exact provider matches, restore queries, and use voice search only where the system supports it
- Open details directly on Play or Resume; artwork is no longer a selectable control and one Back press leaves the detail screen
- Reach the sidebar reliably from every top-level screen; vertical row moves start at the first card and Back returns to Home before showing an exit confirmation
- Keep Library, Discover, Home, and detail content isolated so screens cannot visually overlap after navigation
- Repair legacy Seerr bindings for the unambiguous single-profile setup so Discover content appears again
- Improve missing artwork, safe insets, focus visibility, accessibility semantics, wake behavior, subtitle placement, and playback capability fallback

This remains a beta. Please report the device model, OS version, and exact remote-control steps if you find a focus, playback, profile, or layout issue.

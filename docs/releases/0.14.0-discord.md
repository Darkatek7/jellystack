# Jellystack v0.14.0 — Immersive Jellyfin & Seerr Details

@everyone

Jellyfin playback and Seerr discovery now share a richer, cinematic release.

## What’s new

🎬 **Immersive details everywhere**
Explore Jellyfin movies, series, and episodes plus Seerr Discover, Search, and Requests results in full cinematic detail views.

🔎 **More context before you request**
Browse ratings, cast and crew, seasons, collections, videos, production facts, similar titles, and recommendations without leaving Jellystack.

📥 **Richer request flows**
Request movies or selected TV seasons with searchable profiles, status-aware actions, clear management controls, and in-place updates.

▶️ **Focused Jellyfin controls**
Play or continue, favorite, download, and update watched status from the Command Deck while optional metadata loads independently.

🛠️ **Relevant fixes**
Episodes now use the correct series-owned backdrop and Clearlogo, request state is more resilient, and Settings keeps server management in a cleaner Connections entry.

Jellystack v0.14.0 keeps Jellyfin in charge of playback and user state while making Seerr discovery and requests feel at home in the same polished experience.

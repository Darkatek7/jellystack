# Jellystack 0.14.3 - Implementation plan

1. Add typed Seerr request capabilities and enforce them in state, UI, and submission.
2. Replace connection-form URL checks with a shared Ktor URL validator and add IPv4, IPv6, port, path, and missing-protocol tests.
3. Separate Discover text entry from navigation dispatch and add debounce and stale-request cancellation.
4. Detect Android audio decoders, narrow the Jellyfin direct-play profile, configure media audio focus, and make track selection report success.
5. Re-resolve HLS sources for audio changes while preserving active playback state and rolling back on errors.
6. Update 0.14.3 versions, release notes, privacy documentation, and ignored local integration-test configuration.
7. Run unit, UI compilation, resource parity, debug, release, manifest, signature, artifact, and secret checks.
8. Publish through a pull request, squash-merge after green CI, build the final bundle from main, and tag v0.14.3.
